@@ Mandelbrot
# z -> z^2 + c
$ z0 = 0,  c = the pixel
$ inside if |z| stays <= 2 forever
The most famous object in mathematics: a cardioid with bulbs attached, each with smaller bulbs, and filaments decorated with tiny copies of the whole set.

# Things to try
* Zoom into "Seahorse Valley", the gap between the cardioid and the big circle on its left (about -0.75 + 0.1i).
* Press O and move the mouse. Inside the main cardioid the orbit spirals into a single point. Inside the circle to its left it bounces between two points. Each bulb has its own period.
* Right-click anywhere near the edge to see that point's Julia set.
* Press C for color cycling, just like 1990.

@@ Burning Ship
# z -> (|Re z| + i|Im z|)^2 + c
Take the absolute value of both parts of z before squaring. That small change breaks the smooth symmetry of the Mandelbrot set and gives something jagged. Michael Michelitsch and Otto Rössler described it in 1992. The famous view shows a burning ship with masts and flames, near -1.76 - 0.03i. This app flips the image vertically so the ship sails upright.

# Things to try
* Zoom into the "armada" of small ships along the left antenna.
* Lift it into 3D: the flames become a mountain range.

@@ Tricorn (Mandelbar)
# z -> conj(z)^2 + c
Take the complex conjugate (flip the sign of the imaginary part) before squaring. The result has three-fold symmetry and a three-cornered shape: the "tricorn", named by John Milnor. Its boundary contains curves where the image looks "broken", which don't occur in the Mandelbrot set.

@@ Multibrot
# z -> z^n + c
Raise z to a higher power and the Mandelbrot set grows n-1 fold symmetry. Power 3 has two lobes, power 4 has three, and so on. It's the 2D ancestor of the Mandelbulb, which uses power 8 in 3D.

@@ Newton (z^3 - 1)
# z -> z - (z^3 - 1) / (3 z^2)
Newton's method is a school technique for solving equations: guess, then slide down the tangent line to a better guess. For z^3 = 1 there are three answers (three roots). Arthur Cayley asked in 1879 which root each starting point would find. For real numbers the answer is simple, but for complex starting points the three basins meet in an infinitely intricate fractal: wherever two colors meet, the third is there too.

Each basin gets its own part of the palette ("Root color spread"), and the bands show how many steps it took.

@@ Phoenix
# z -> z^2 + c + p * z_previous
Shigehiro Ushiki's 1988 formula remembers the previous value of z as well as the current one. The extra memory creates swirling, feathery shapes. The classic Julia version uses c = 0.5667 and p = -0.5.

# Things to try
* Tick "Julia set", then set c real = 0.5667, c imag = 0 and Phoenix p = (-0.5, 0).

@@ Lambda
# z -> lambda * z * (1 - z)
The complex version of the logistic map, the population model that made "chaos" famous (Robert May, 1976). In the parameter plane (Julia unticked) we start from the critical point z = 1/2 and vary lambda. Its Julia sets are Fractint classics: right-click the parameter plane to explore them.

@@ Magnet I
# z -> ((z^2 + c - 1) / (2z + c - 2))^2
This comes from physics, not art: renormalization studies of magnetic materials (the Ising model) produce this map. It has two kinds of attracting behavior: escape to infinity, or settle at z = 1. The fractal is where the two compete. Fractint shipped it as the magnet1m and magnet1j types.

@@ Custom formula
# Write your own, the Fractint way
Fractint's most loved feature was the formula file: a few lines of text that define a whole new fractal. The same works here.
$ Name { init : loop, test }
$ Spider { z = c = pixel : z = z*z + c, c = c/2 + z, |z| <= 4 }
Everything before the colon runs once per pixel; after it comes the loop, and its last line is the "keep going" test. When the test becomes false, the pixel is colored by how many steps it took. |z| is the squared size of z, exactly as in Fractint.

# Things to try
* Pick a formula from the list, then press "Edit formula..." and change a number. Ctrl+Enter compiles it.
* FnMandel with fn1 = sin, cos, exp or cosh: one formula, four different worlds.
* "Lift into 3D landscape" works with your formula too.
* Put your own .frm files in ~/.config/fract3d/formulas, or drop one onto the window.

# Smooth colors for your formula
Smooth coloring needs to know how far out the escape circle is and how fast z grows. The circle is read from a test like |z| <= 4 (radius 2). For other tests, or maps that aren't squares, add comment lines inside the formula:
$ ; @bailout = 8     escape radius (|z| > 8 counts as escaped)
$ ; @power = 3       z grows like z^3
$ ; @smooth = 0      keep whole-number bands

@@ Coloring: Binary decomposition
# Which half-plane did z escape into?
At the moment z escapes, look at the sign of its imaginary part and shift the color by half a palette when it's positive. The bands split into a checkerboard of cells.
$ color = iterations + (Im z > 0 ? 128 : 0)
Each cell is the set of starting points whose orbits escape through the same "gate" at the same step. Following the cells inward traces the external rays that Douady and Hubbard used to prove the Mandelbrot set is connected. Fractint called this option "decomp".

@@ Coloring: Escape angle
# Color by direction, not by time
Instead of counting steps, color by the angle of z as it escapes: arg(z), from -pi to pi, mapped around the palette.
$ color = arg(z_escape) / 2pi
The result shows how the outside of the set is "combed": angle lines flow toward the boundary. Fractint's "atan" outside coloring did the same.

@@ Coloring: Stripe average
# The average of a wiggle
While iterating, keep a running average of sin(k * arg z) over the whole orbit. Points whose orbits wind the same way get the same shade, which paints fine stripes that follow the set's filaments. The final value is blended between the last two averages using the fractional escape count, so the stripes stay smooth.
$ color = mean over the orbit of 0.5 + 0.5 sin(k arg z_n)
Jussi Harkonen introduced it in 2007. "Stripe density" is k: higher values give more, thinner stripes.

@@ Coloring: Orbit trap: cross
# How close did the orbit come to the axes?
Track the smallest distance from any z_n to the real or imaginary axis. Orbits that brush past an axis get one color, orbits that keep their distance another. The traps reveal cross-shaped structures that repeat at every scale. It's the same idea the 3D fractals here use for their "orbit trap" colors.
$ color = min over n of min(|Re z_n|, |Im z_n|)

@@ Coloring: Orbit trap: point
# How close did the orbit come to a point?
Track the smallest distance from any z_n to a fixed point (set by "Trap size"). Every time an orbit passes near the point it leaves a bright dot, so the picture fills with little circles strung along the filaments.
$ color = min over n of |z_n - trap point|

@@ Coloring: Biomorph
# Creatures from a bug
In 1986 Clifford Pickover wrote a Julia-set program with a small mistake: his escape test checked the real and imaginary parts separately instead of |z|. Points that escaped with one part still small were drawn in the "inside" color, and cell-like, organic shapes appeared: he called them biomorphs, and they became a Fractint favorite.
$ escape when |Re z| > L or |Im z| > L
$ "inside" if either part is still < L
Try it on Julia sets and with higher powers (Multibrot).
