# Fract3D peer review — 2026-09-25

Independent review of the initial implementation (~4,900 lines across `src/`, `shaders/`,
`fractals/`). Every source file was re-read from disk. Nothing has been changed; this is a
work list. File references are relative to the repo root; line numbers are as of this date.

Priority tags: **[P1]** fix first (crash/hang/data loss), **[P2]** real bug or robustness gap,
**[P3]** quality/cleanup, **[ENH]** enhancement.

---

## 0. Overall assessment

Architecture is sound; nothing structural needs to be torn up. Strong points worth keeping:

- Self-describing fractal files (`@param` / `@look` / `@about` → sliders, look, lesson) with hot reload.
- Signature-based progressive accumulation (hash state, restart on change, batch samples when still).
- Headless `--render` / `--ui-shot` harness (seed of a regression suite).
- Correct details: sRGB palette texture + linear-space averaging, NaN/Inf guards before accumulation,
  ordered PBO probe readback, `#line`-mapped shader errors, compile-then-swap on reload, camera
  snapshot for poster renders.

Weaknesses are mostly robustness (GPU-hang paths, unchecked GL failures, unvalidated PAR input)
plus a handful of real correctness bugs.

**Caveat carried over from the build session:** the interactive input paths (orbit, fly,
double-click pick, 2D pan/zoom/Julia toggle) have only been reasoned about, never exercised in a
real window. Do that before trusting any of them.

## 1. Bugs and correctness

### 1.1 [P1] Interactive 2D render can hang the GPU
- `src/app.cpp:654` (`render2D`) and `src/renderer.cpp:275` draw the whole iteration buffer in one
  full-screen draw call, no tiling.
- `+` key doubles `maxIter` up to 2^20 (`src/app.cpp:397`); a hand-edited PAR can set anything.
- Zoomed out, most pixels are inside the set and run the full count: 5120×1440 × ss² × 1M
  iterations is a multi-minute single dispatch. NVIDIA on Linux has no watchdog by default → desktop
  freeze.
- **Fix:** tile the interactive 2D render across frames with a time budget, as `updatePoster`
  already does (`src/app.cpp:717`). Rendering in horizontal bands gives Fractint's scanline reveal
  for free. Also cap `maxIter` from the `+` key and clamp on PAR load.

### 1.2 [P2] Unvalidated PAR values reach array indices
- `readVals` in `src/params_io.cpp:193` writes straight into settings.
- `cs.formula = 12` in a PAR → `kClassicFormulas[cs.formula]` out-of-bounds read at
  `src/ui.cpp:315` and in the Learn panel (`src/ui.cpp:791`).
- Same class: `tonemap`, `insideMode`, `colorMode`, `retro`, negative `maxSteps` / `bounces`,
  `pixelSize`, `power`. (`supersample` and `palette` are already clamped.)
- **Fix:** a single `clampSettings()` pass after `loadPar` (and after CLI overrides).

### 1.3 [P2] No framebuffer / texture allocation checks, no GL debug output
- `RenderTarget::ensure` (`src/gl_util.cpp:116`) never calls `glCheckNamedFramebufferStatus` or
  checks `GL_MAX_TEXTURE_SIZE`.
- Example: 8K poster in 2D at 4× supersampling requests a 30720×17280 RG32F texture (4.2 GB) →
  silent failure → black PNG after a long wait.
- No `GL_DEBUG_OUTPUT` callback anywhere.
- **Fix:** check completeness in `ensure` (return bool, surface a toast), clamp poster size ×
  supersample to `GL_MAX_TEXTURE_SIZE`, install a `glDebugMessageCallback` (at least in
  non-Release builds, ideally behind `--gl-debug`).

### 1.4 [P2] Poster renders snapshot the camera but not lighting / params
- `src/app.cpp:701` captures `View3D` and `cs`; `updatePoster` (`src/app.cpp:729`) reads live `rs`
  and live fractal param values.
- Changing a light slider mid-render blends two scenes into one accumulation.
- **Fix:** snapshot `rs` and the effective param values into `poster` at `startPoster`.

### 1.5 [P2] Wayland fullscreen path emits GLFW errors; wrong monitor
- `src/app.cpp:364` and the duplicate at `src/ui.cpp:282` call `glfwGetWindowPos`, unsupported on
  Wayland → error callback fires on every F11; position restore is a no-op.
- Always uses the primary monitor rather than the one the window is on (matters on ultrawide + TV).
- **Fix:** one `toggleFullscreen()`; pick the monitor by window overlap
  (`glfwGetMonitors` + `glfwGetMonitorWorkarea`); skip `glfwGetWindowPos` on Wayland
  (`glfwGetPlatform() == GLFW_PLATFORM_WAYLAND`).

### 1.6 [P2] `rotAxis` is a transposed rotation
- `shaders/common.glsl:15` documents itself as "rotates by −angle" because the `mat3` literal is
  column-major; `fractals/sierpinski.glsl` compensates with a negated angle.
- **Fix:** transpose the literal so it's a proper +angle rotation; update sierpinski's call.

### 1.7 [P2] `xdg-open` via `std::system` with string concatenation
- `src/ui.cpp:196`. A path containing `'` breaks it; a hostile path injects.
- **Fix:** `posix_spawn` / `fork+exec` with an argv.

### 1.8 [P2] `classic.fp64` is not persisted
- Missing from `visitSettings` (`src/params_io.cpp:62`). Preset `03-deep-zoom-fp64` sets it, but
  the line is ignored; works only because 2 (auto) is the default.
- **Fix:** add `f("classic.fp64", &c.fp64, 1)`; consider also `classic.showOrbit`.

### 1.9 [P2] "Lift into 3D" discards the current palette
- `src/app.cpp:785`: `selectFractal(li, true)` → `applyLook` overwrites `rs.palette`. Lifting the
  VGA Mandelbrot lands on "Ultra Fractal". The button's purpose is continuity.
- **Fix:** save `rs.palette` before `selectFractal`, restore after; probably also carry
  `cs.colorDensity` ↔ `rs.colorScale` both ways (`flattenTo2D` doesn't restore it either).

### 1.10 [P3] Smaller correctness items
- Double-click "moves the orbit center" but actually does a `lookAt` that snaps the view
  (`src/app.cpp:630`). With target = pos + fwd·d that's the only option; either animate the
  transition (short slerp) or word the toast honestly.
- Ground plane only intersected when the camera is above it (`shaders/raymarch.frag:94`); it
  vanishes from below. `shaders/probe.frag` ignores the floor entirely, so fly-speed doesn't slow
  near it.
- `Hit.minD` computed and never used (`shaders/raymarch.frag:87,100`); drop it or use it for glow.
- `Program::loc` constructs a `std::string` per lookup (`src/gl_util.cpp:108`): ~50 heap
  allocations per sample. Use `std::string_view` keys with heterogeneous lookup, or cache
  locations in a per-program struct.
- Every fractal switch (incl. `1`–`9` keys) runs `applyLook` and wipes the user's lighting tweaks
  (`src/app.cpp:189`). Defensible default; add a "keep my lighting" toggle or only apply the look
  when the user hasn't touched lighting since the last switch.
- `applyLook`'s manual field-by-field reset (`src/app.cpp:197`) is a second hand-maintained list
  of "look-ish" fields beside `visitSettings`; derive one from the other.
- `liftTo3D` silently maps Newton/Phoenix/Lambda/Magnet to Mandelbrot (`src/app.cpp:772`);
  toast a message or disable the button for those formulas.
- `loadPrefs` doesn't clamp `flySpeed` (0 or negative disables flight).
- `Ctrl+S` with an empty `parName` writes `.par`.
- 2D wheel zoom updates `cx/cy` before clamping `height` (`src/app.cpp:509`); at the clamp the
  center drifts.
- `fps` uses `dt` clamped to 0.1 s, so it never reads below 10 after a stall (cosmetic).

## 2. Design and code quality

### 2.1 [P2] Bytewise settings signature is fragile
- `src/state.h` forbids `bool` and relies on zero padding so `appendBytes(s, rs)`
  (`src/app.cpp:540`) is stable. The `static_assert(sizeof % 8 == 0)` on `Classic2DSettings`
  catches tail padding only; `RenderSettings` has no assert at all. Adding a `double` or `bool`
  later silently makes accumulation restart every frame (or never).
- **Fix:** build the signature memberwise via `visitSettings` (or a sibling visitor). Then
  `bool` fields become legal and the `bool sh = rs.shadows; if (Checkbox) rs.shadows = sh;`
  dance in `ui.cpp` disappears.

### 2.2 [P3] `App` is a god object
- ~160 public fields; `ui.cpp` reaches into all of them; `lib_` / `current_` carry private-style
  underscores while being public.
- Suggested split: `ViewState` (mode, cam, rs, cs, params), `Session` (prefs, paths, poster),
  `Ui`. Do it before the next thousand lines.

### 2.3 [P3] State hidden in function-local statics
- `coreSig` in `render2D` (`src/app.cpp:664`), `lastCheck` in `frame()` (`src/app.cpp:286`),
  `stops` in the Tour tab (`src/ui.cpp:811`), `classic` text (`src/ui.cpp:788`),
  `shown` in `frame()` (`src/app.cpp:315`).
- Non-reentrant, untestable, and the Learn caches mean new presets/docs need a restart despite
  everything else hot-reloading. Move to members; reload docs/presets on mtime like the shaders.

### 2.4 [P3] Dead code / fields
- `App`: `mapPalettes`, `lastMouseX/Y`, `lastClickTime`, `scrollAccum`, `lastBatch`,
  `lastRenderScale`; `flying` is set but never read; `parNote` written, never read.
- `parseFractalFile`: `firstCodeLine`.
- `Renderer`: stored `classic_` / `display_` source strings unused after build.
- `glfwSetWindowUserPointer(win, this)` unused.

### 2.5 [P2] No tests, no VCS
- Not a git repo yet. `git init` before anything else; vendor ImGui as a subtree or submodule.
- Add a CTest that runs `--render` on every fractal and every preset at ~64×36: a shader-compile
  regression check that takes seconds. Golden-image diff with tolerance on top for rendering
  regressions. The harness exists; this is ~20 lines of CMake plus a script.
- Consider a Debug preset with `-fsanitize=address,undefined`.

## 3. Rendering quality

### 3.1 [ENH, high value] Sampling is white noise
- `pcgHash` per pixel per frame (`shaders/common.glsl`) → slowest possible path-tracing
  convergence and ugly unconverged frames.
- Stratified / low-discrepancy sampling (Sobol + Owen scrambling, or R2 + Cranley-Patterson
  rotation) typically halves samples for equal noise; a blue-noise mask for the first samples makes
  the in-motion image look far better. Single biggest visual win available.

### 3.2 [P2] Glossy paths have no next-event estimation
- `shaders/raymarch.frag:267` (glossy branch) does no NEE, and bounced rays hit the sky with
  `withSun = false`. Net: in path-traced mode no surface ever shows a sun highlight; the landscape
  lake reflects sky only.
- **Fix:** NEE in the glossy branch weighted by the BRDF lobe (or MIS between BSDF sampling and
  the sun cone).

### 3.3 [P2] Landscape DE isn't a distance
- `fractals/landscape.glsl` returns `p.y − h`; the 0.4 step factor papers over it, and overshoot
  speckle is visible on ridges in renders.
- **Fix:** dedicated heightfield marcher: coarse fixed steps + bisection refinement, or a
  cone-step / Lipschitz bound on the height function. This sharpens the most Fractint-flavored
  fractal in the set.

### 3.4 [P3] Other rendering notes
- Real-time AO radius scales with hit distance (`h.t * 0.06`, `shaders/raymarch.frag:214`), so
  shading changes as you approach. Common practice; note it if "flicker" is reported.
- Step-count AO (`raymarch.frag:215`) depends on `uMaxSteps`, so the Max-steps slider changes the
  look, not just quality.
- `retroQuantize` loops 248 palette entries per pixel (`shaders/display.frag:78`). Precompute a
  32³ 3D LUT texture → one fetch.
- First use of each fractal compiles two programs on the render thread (~100–300 ms hitch,
  `src/renderer.cpp:146`). Use `GL_KHR_parallel_shader_compile`
  (`glMaxShaderCompilerThreadsKHR`, poll `GL_COMPLETION_STATUS`) or warm up all programs at start.
- When converged and nothing animates, the main loop still spins at vsync (`src/app.cpp:264`).
  `glfwWaitEventsTimeout` in that state drops idle GPU/CPU to near zero.
- fp64 switch threshold `2e-6` px (`src/renderer.cpp:272`) is conservative: float still has ~30
  ULPs/pixel there, and GeForce fp64 is 1/64 rate. ~4e-7 is safe; perturbation theory (§4.4) is
  the real answer.
- Color cycling in 3D restarts accumulation every frame even when `colorMode` is Normal/Flat
  (`src/app.cpp:546`); skip the offset in the signature for those modes.
- Fog turns the whole sky into flat fog color (`raymarch.frag:319`, `t < 0 → 1e9`); consider
  fading only up to the sky's horizon so the sun disc survives.
- 2D iteration buffer at 4× SS on 5120×1440 is ~944 MB (RG32F). Fine on 32 GB, but consider
  R32F + a separate 8-bit aux, or storing half floats for the aux channel.

## 4. Enhancements that fit the brief (nostalgia + teaching + GPU showcase)

Ranked roughly by nostalgia-per-hour.

1. **[ENH] Formula files.** Fractint's `.frm` was *the* feature. The app already compiles GLSL at
   runtime; a small expression parser that transpiles `z = z^2 + c` / `z = sin(z) + c` into a
   generated fractal file gives "type a formula, see the fractal" in 2D and 3D-landscape modes.
2. **[ENH] Progressive scanline 2D rendering.** Fixes §1.1 and looks like 1990.
3. **[ENH] Julia preview inset.** Fractint's Space/`J` showed a small live Julia set for the point
   under the cursor. A second tiny `render2D` into a corner texture; teaches the
   Mandelbrot–Julia relationship better than any paragraph.
4. **[ENH] Perturbation-theory deep zoom** for 2D: reference orbit in arbitrary precision on the
   CPU (MPFR), delta orbits in fp32 on the GPU; PAR stores the center as a decimal string.
   10^100 zooms with the 5090 idling.
5. **[ENH] Camera-path recording + video export** (keyframes, pipe frames to ffmpeg).
6. **[ENH] Undo/history**: Ctrl+Z ring of state snapshots (camera + rs + cs + params).
7. **[ENH] Right-drag cursor capture** (`GLFW_CURSOR_DISABLED` + raw mouse motion) so look-around
   isn't limited by the screen edge. Gamepad flying via GLFW joysticks on top.
8. **[ENH] Embed the PAR in the PNG** as a `tEXt` chunk instead of a sidecar (stb can't; a 30-line
   chunk writer or lodepng can). Then any screenshot is reloadable by drag-drop.
9. **[ENH] More 2D coloring modes**: potential, decomposition, biomorph, stripe / orbit traps —
   cheap, each is a Learn lesson.
10. **[ENH] Gradient-stop palette editor** (Fractint's was legendary; the cosine editor is thin).
11. **[ENH] Auto-save session on exit / restore on start.**
12. **[ENH] Fullscreen on the current monitor** (see §1.5).

## 6. Verified-correct items (no action; recorded so they aren't re-litigated)

- VGA power-on palette construction (`src/palettes.cpp`): EGA 16, 16 grays, 9 rings × 24 hues at
  the standard 6-bit levels, 8 black — matches the real DAC table.
- `rotX/Y/Z` and `rotEulerDeg` are correct (column-major handled); only `rotAxis` is transposed.
- DE formulations: Mandelbulb, Mandelbox, Menger, quaternion Julia, Apollonian, pseudo-Kleinian
  are the standard forms; Sierpinski/KIFS `length(z) − 1` is a safe underestimate.
- Fractint band indexing (escape at iteration *i* → palette entry *i*+1; entry 0 reserved for
  inside) and smooth-iteration formula are correct.
- `Classic2DSettings` has no interior padding at present (all doubles 8-aligned; total 112 bytes).
- sRGB handling: palette texture is `SRGB8_ALPHA8`, averaging happens in linear, single
  `linearToSrgb` at the end; default framebuffer is not sRGB-enabled, so no double conversion.
- Probe PBO double-buffer + fences: issue/consume order is consistent; tags only pushed on
  successful issue.
- Learn-panel history/attributions checked: Shishikura 1998, Brooks–Matelski 1978, Tyler 1988,
  Hart–Sandin–Kauffman 1989, White–Nylander 2009, Lowe 2010, Michelitsch–Rössler 1992,
  Ushiki 1988, "FRACTal INTeger" — all correct.
